# Style menu: pick by situation

Offer the user the situation that matches their topic, then 3-4 styles from it. Each pick: `id` - why. Effort and engine are in `all-styles.md`.

## 1. Tech, system design, apps, startups, product explainers
- **Clean UI cards** (`ui-cards/clean-ui`, ui-cards) - Default. Cheapest, cleanest, works for any app/system topic
- **Dark Tech Keynote** (`lemo/dark-keynote`, lemo-opuscar) - Dark stage, one giant number, launch-event feel
- **Living Screencast** (`lemo/living-screencast`, lemo-opuscar) - Rebuilt UI with a moving cursor: tutorials and feature walkthroughs
- **ASCII / CRT Terminal** (`lemo/ascii-crt`, lemo-opuscar) - Retro terminal flavour for infra/logs-heavy topics
