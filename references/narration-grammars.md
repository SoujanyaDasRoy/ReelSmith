# Narration grammars (how the voice and visuals take turns)

Nine explainer grammars from huashu-art-motion (paraphrased; credit alchaincyf), plus ours. Choose one per reel and keep it.

| Id | Grammar | Visual behaviour | Good for |
|---|---|---|---|
| y1 | Kurzgesagt | One concrete object in a glowing world; scale zoom-ins and outs | Big-picture science, "how huge is X" |
| y2 | Vox | Real-material collage, red line annotations, highlighter | News/analysis, comparisons |
| y3 | Whiteboard | Things are written/drawn as the narrator says them | Step-by-step logic, definitions |
| y4 | Storytime | Character reactions with punchline pauses (needs your own character frames) | Anecdotes, comedy |
| y5 | Kinetic type | Keywords slam in, one focus word at a time | Hooks, listicles, rhythm |
| t1 | 3Blue1Brown | Math shapes morphing on dark background | Math/algorithms (Manim engine) |
| t2 | Keynote UI | One point per screen, screenshots/UI, big numbers | Product, system design (our ui-cards) |
| t3 | Finance chart | Axes first, then data grows, one highlight | Numbers, markets, metrics |
| -  | Presenter-led finance | Card/code snapshot only; needs own character assets | Talking-head style |

Mapping to this skill: **t2 = our default (ui-cards)**; t3 = ui-cards with a chart card; y3 = whiteboard look via anidoodle chalkboard/marker; t1 = Manim.

Voice rules that go with any grammar
- Write the Hindi so each visual beat has one cue word; the beat enters on that word, not before.
- One new idea per sentence. Pauses are earned: use `tail` after a punchline, not extra words.
- Comedy: deadpan understatement; names/catchphrases only for real people (no impersonation); the joke lives in one line, not a bit.
